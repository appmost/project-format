# Appmost Project Format 2.17.0

Appmost Project Format 2.17.0 extends [2.16.0](https://www.appmost.ai/format/spec/2.16.0.md). The package uses `documentVersion: 2`.

## Horizontal bar comparisons

A `barChart` may set `barOrientation` to `horizontal` or `vertical`. Omission retains the existing vertical appearance. Horizontal bars use a shared signed scale covering zero and all finite values; negative values extend left and positive values right. All-zero data places the baseline at the center.

When `showXAxis` is enabled, `zeroLabel` optionally supplies text for the zero baseline. For horizontal charts, when `showBarValueLabels` is enabled, a point's optional `valueLabel` supplies its displayed and accessible value. Otherwise the numeric value is formatted normally. A binding can specify `valueLabelProperty` to read display text from the same list item as its numeric `valueProperty`. These display labels never replace the numeric data used for geometry.

Appmost Design edits fixed chart values. Appmost can also configure supported list bindings. Platform availability is described by the registry.
