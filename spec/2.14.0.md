# Appmost Project Format 2.14.0

Appmost Project Format 2.14.0 extends [2.13.0](https://github.com/appmost/project-format/tree/spec-v2.13.0). The package still uses `documentVersion: 2`.

## Row long-press actions

`longPressActions` is an optional array on a normal row or child row. Its items use the same AppAction definitions as `appActions` and run in document order. Appmost on iOS, iPadOS and Android runs the array once when the native long press is recognized. A recognized long press consumes the gesture and runs only the long-press actions. It preserves the row's checked state. Normal tap actions remain independently available. An omitted or empty array keeps the row's regular interaction.

Native controls within a row retain their own gestures.
