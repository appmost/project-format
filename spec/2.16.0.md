# Appmost Project Format 2.16.0

Appmost Project Format 2.16.0 adds native skeleton loading settings. Packages continue to use `documentVersion: 2`. See [2.15.0](https://www.appmost.ai/format/spec/2.15.0.md) for the previous release.

`appGlobalUISettings.loadingStyle` selects `spinner` or `skeleton` in the version document. `appGlobalUISettings.skeletonRowCount` sets the number of placeholder rows for an empty server-backed list. The supported count is 1 through 20, with a default of 5.

`listProperties.loadingStyle` and `listProperties.skeletonRowCount` in a page override the corresponding app defaults. Omission or `null` leaves a setting inherited. An omitted app style retains the spinner used by existing projects.

SwiftUI and Jetpack Compose can render the authored row layout as placeholders during a server fetch. Already available rows can remain visible while missing list content loads. The wireframe toggle is an editor preference.
